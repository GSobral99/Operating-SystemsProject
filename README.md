# Park-IUL — Sistema de Gestão de Estacionamento

Projeto académico de Sistemas Operativos (ISCTE-IUL, 2024/2025).
Implementa um sistema cliente-servidor de gestão de parque de 
estacionamento em três fases progressivas.

## Parte 1 — Shell Scripting
Scripts Bash para registo de entradas/saídas, manutenção de dados
e geração de estatísticas em HTML.

## Parte 2 — Processos e Sinais
Modelo cliente-servidor em C usando fork(), sinais (SIGUSR1/2, 
SIGALRM) e FIFOs para comunicação síncrona.

## Parte 3 — IPC (System V)
Evolução do módulo anterior usando Message Queues, Semáforos e
Memória Partilhada para concorrência entre processos.

## Tecnologias
Bash, C, Linux IPC (msgget/semget/shmget), sinais POSIX
